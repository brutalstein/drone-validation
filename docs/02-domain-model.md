# Domain Model

Requirement: traceable engineering claim with stable ID and acceptance rule.

Scenario: versioned experiment definition containing time model, adapter, environment, test conditions, assertions and seed.

Controlled condition: reproducible perturbation with target, start, duration and parameters.

Assertion: machine-evaluable requirement check.

Run: immutable execution of one resolved scenario against one exact system build.

Campaign: collection of runs generated by a search strategy.

Evidence bundle: manifest plus time-series, log, trace and artifact files with hashes.

Replay descriptor: enough information to resolve software versions, scenario, parameters, seed, adapters and clock behavior.

Digital twin: composition of plant, environment, sensors, compute, network and software models at declared fidelity.

Credibility record: evidence that a model is appropriate for a specific validation question and operating envelope.
