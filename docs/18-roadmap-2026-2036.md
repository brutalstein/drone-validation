# Roadmap 2026-2036

The roadmap is capability-based, not a delivery-date promise.

## 2026-2027: foundation

- deterministic C++ core;
- versioned scenario and evidence schemas;
- modern Gazebo + PX4 SITL reference adapter;
- ROS 2 LTS observation support;
- MCAP evidence recorder;
- controlled degraded-condition injection;
- grid and bisection campaign search;
- reproducible containerized runner;
- CI, SBOM and provenance groundwork.

## 2027-2028: laboratory

- HIL gateway and rig capability model;
- time synchronization and latency characterization;
- hardware reservation service;
- DDS and Zenoh transport comparison;
- OpenTelemetry distributed tracing;
- evidence explorer and control-plane API;
- parameter-space coverage metrics.

## 2028-2030: assurance fabric

- Bayesian and evolutionary boundary search;
- multi-fidelity optimization;
- simulation credibility records;
- cross-simulator differential testing;
- FMI integration;
- HLA federation adapter;
- SysML v2 requirement and verification synchronization;
- signed artifacts and mature provenance.

## 2030-2033: scale

- mixed-fidelity campaign scheduling;
- remote hardware farms;
- benign multi-vehicle coordination validation;
- data-quality and distribution-shift analysis for learning-enabled components;
- surrogate models that reduce expensive HIL use;
- organization-wide regression baselines;
- pluggable enterprise policy engine.

## 2033-2036: continuous assurance

- runtime evidence ingestion;
- digital-thread continuity from requirement to operational evidence;
- automatic impact analysis when software, models or requirements change;
- AI-assisted root-cause triage with evidence citations;
- cross-domain autonomous-system validation using the same canonical experiment model.

## Architectural bets

Stable IDs outlive tools.
Evidence formats stay open.
Adapters absorb ecosystem churn.
Search algorithms stay replaceable.
Simulation credibility is explicit.
Hardware safety remains independent.
